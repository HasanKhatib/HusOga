# HusÖga Strategy

## Current Focus — MVP

Ship a polished MVP targeting house buyers at visningar. The priority improvement is a detailed, shareable report (PDF export) with the disclaimer embedded. All UI copy uses "kondition" / "underhållsbehov" framing — not "risk." No backend, no accounts, no marketplace. Prove the tool first.

## Future Vision

*Nothing below is decided. These are directions worth exploring — all require validation before any commitment.*

**Market** — Potential integration with Hemnet or Booli as a data enrichment partner once usage volume is proven. Almi funding is a possible path if marketplace traction can be demonstrated. The "kondition" framing makes the product viable for platforms that would never touch a "risk" label.

**Product** — A "Boka besiktning" CTA on the result screen as a second revenue stream, using a quote-first flow rather than instant booking. The booking marketplace would be a separate product, not a feature bolt-on. IAP for the full report and a transaction fee for bookings are two distinct revenue lines.

**Besiktningsman domain** — Pre-assessment data shared with the booked inspector before arrival makes the platform sticky on the supply side. The output must never be called a besiktningsprotokoll — it is a digital konditionsöversikt, not a licensed inspection.

**Legal** — Any marketplace handling real payments requires an AB, explicit platform-not-guarantor terms, GDPR compliance, and verified SBR credentials for all listed besiktningsmän before launch. The existing disclaimer stays prominent in all exported output.
